# PadhAI documentation

All of PadhAI's documents, by what you need to do. If you are new, start with [start-here.md](start-here.md).

Each topic has **one authority**: the page marked ★ in each section. Other pages link to it rather than repeat it.
Pages written from the code say which commit they were checked against.
