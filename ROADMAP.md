# Roadmap — backend

Deferred work for THIS repository: the Python AI backend, the tunnel, the
self-hosted stacks and the browser suites.

**The frontend has its own roadmap.** Dashboard UX, Convex functions, auth, email
and the read-amplification work all moved to `ayurveda-frontend/ROADMAP.md` when
the frontend was split out. Nothing about `packages/` or `apps/app` belongs here
any more — if you are looking for it, look there.

---

## 1. GraphRAG is now the only backend — 2026-08-29

Reversed from the entry this replaced. The local knowledge base, the local
LLM chain, the intake/gathering conversation, and every fallback (offline
notes, `LOCAL_RAG_ENABLED`) have been deleted, not just switched off. Every
consultation now goes straight to GraphRAG's `/v1/answer`; the only thing
still decided locally is the safety keyword scan in `src/safety.py`, which
runs before that call.

What this costs, so it is not rediscovered as a surprise:
- **No fallback.** An outage of GraphRAG is now a plain error, full stop —
  there is no note to render and no second provider to fall through to.
- **No conversation memory.** `/v1/answer` takes only `query` and `k`, so a
  follow-up like "explain that in English" is sent with no prior answer
  attached and may not land the way it used to.
- **No intake questions.** The multi-turn "ask a couple of clarifying
  questions, then plan" conversation is gone; every message is answered on
  its own.
- The earlier latency and graph-quality numbers recorded here (2.4-7.3s
  calls, 444/600 edges as bare `MENTIONS`) were about the *retriever* path,
  which no longer exists. They may or may not still describe `/v1/answer`
  itself — worth asking the vendor rather than assuming either way.

## 2. The contract changed, and it needs a frontend PR

`docs/consult-contract.json` (generated by the now-deleted
`scripts/export_contract.py`) has been removed rather than left stale.
`docs/api-contract.md` is updated by hand instead: `context` is no longer
read, `POST /api/upload` no longer exists, and `sources` only ever carries
`graphrag:` entries now. The frontend's own contract test will be red until
it is updated to match — that is the coordinated release working as
intended, not a regression to route around.

## 3. Production-readiness

- **Named Cloudflare tunnel + real domain** — replaces the ephemeral
  `*.trycloudflare.com` URL, which changes whenever `cloudflared` restarts. This
  also unblocks Google OAuth in the frontend repo, which needs a stable redirect
  URI. `cloudflare/config.yml` and `cloudflare/zones.mjs` are here.
- **Strong `INSTANCE_SECRET`** for the self-hosted Convex backend — still the
  compose default in `self-hosted/`. Must change before any real use.
- **GlitchTip** (`self-hosted/glitchtip/`) is up and verified end to end. The stack
  lives here; the app-side DSN wiring lives in the frontend repo. Set
  `ALLOWED_HOSTS` before a real deployment.

## 4. Content

Moot now — there is no local corpus to curate. Naming Ayurvedic medicines,
and everything else about what the answer contains, is entirely GraphRAG's
content and the vendor's decision, not something edited in this repo any
more.
